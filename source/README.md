# Dev Kit source assets

Copy this folder's Local directory and modinfo.json into UE4/Content/Mods/SuzumuMotorcycle in a matching official Conan Exiles Enhanced Dev Kit.

The Local directory is physical storage. Object references use /Game/Mods/SuzumuMotorcycle without Local.

The source contains the custom horse subclass, its additive ModController, 11 custom data tables, the supplied motorcycle model and imported materials/textures. It does not contain extracted stock game assets. The installed game's horse classes are referenced as dependencies.

For installation, requirements, validation status and credits, see the README.md in the parent project. The supplied model's personal-use license remains applicable. This local project was authored with Codex and universal-modder.
