# Suzumu Motorcycle

Локальный мод для Conan Exiles Enhanced, созданный в официальном Dev Kit UE 5.8.2 (CL 378787) под установленную игру CL 379176.

**Статус: собранный прототип, полная проверка езды ещё не завершена.** Подтверждены компиляция, загрузка контроллера в Play In Editor, создание транспорта из предмета, встроенное сиденье, компонент питомца, инвентарь, атрибуты и параметры скорости. Посадка синтетического тестового персонажа не завершилась; обычная лошадь в том же окружении показала такую же проблему. Фактические скорость, расход выносливости во время езды и сохранение/загрузка требуют проверки обычным игровым персонажем.

## Что добавлено

- Предмет «Мотоцикл Suzumu», ID **19871001**, на основе лошади, с одним местом и 10 ячейками.
- Атрибуты начинаются с 15; рост, уровни, перки и взаимодействия наследуются от лошади.
- Параметры обычной езды 60 км/ч, спринта 120 км/ч; выносливость ездового существа 1600 и расход спринта 1/с.
- Дополнительное уменьшение входящего урона от падения на 50%; прочий урон не меняется.
- Встроенное сиденье, ID **19871002**, для езды без отдельного седла.
- Рецепт на Artisan Table: **200 Hardened Steel Bar + 50 Hardened Leather + 100 Steel Reinforcement**.
- Талант «Механик Suzumu»: уровень 40, 25 очков, Survival, родитель Apprentice Tinker.
- Предоставленная модель Suzumu, длина 2,2 м, локальные текстуры. Вращение колёс пока не анимировано.

## Установка локального пакета

Готовый файл: `dist/SuzumuMotorcycle.pak`.

Закройте игру и скопируйте его в:

```text
D:\Steam\steamapps\common\Conan Exiles\ConanSandbox\Mods\SuzumuMotorcycle.pak
```

Добавьте в `ConanSandbox\Mods\modlist.txt` строку, сохранив остальные моды:

```text
*SuzumuMotorcycle.pak
```

Скрипт `scripts/install_local.ps1` выполняет эти действия и сохраняет прежние modlist.txt и одноимённый пакет в `private/install-backup-*`. На частном сервере нужен тот же пакет и тот же порядок загрузки у всех игроков.

## Исходники и повторная сборка

`source/Local` содержит собственные ассеты мода, `source/modinfo.json` — метаданные. Рабочая копия находится в Dev Kit: `UE4/Content/Mods/SuzumuMotorcycle`.

Виртуальные пути ассетов начинаются с `/Game/Mods/SuzumuMotorcycle/`. Физическая папка `Local` в эти пути не входит.

Закройте Dev Kit и запустите из корня рабочей папки:

```powershell
& './SuzumuMotorcycle/scripts/build_mod.ps1'
```

`scripts/author_tables.py` воспроизводит строки таблиц из установленного Dev Kit, а `scripts/author_behavior.py` — поведение и контроллер. Импорт модели выполняет `scripts/import_model.py`. Эти скрипты запускаются внутри Python официального Dev Kit.

## Проверка перед обычным использованием

В отдельном одиночном мире проверьте открытие таланта и списание 25 очков, рецепт и материалы, размещение предмета, посадку без седла, инвентарь, разгон/спринт, расход выносливости, падение, рост уровня и повторную загрузку сохранения. Сравнивайте движение по ровной поверхности без серверных модификаторов скорости.

Результаты исследования и конкретные проверенные параметры приведены в `MODDING_PLAN.md`; технический журнал — `MODLOG.md`.
